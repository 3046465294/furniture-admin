## 一、风格定义（两条腿走路）

| 维度 | 采纳来源 | 具体含义 |
|---|---|---|
| **配色 + 质感** | 苹果（Apple） | 白/浅灰底 + 单一主蓝 + 液态玻璃（磨砂半透明浮层） |
| **信息布局** | 京东 / 拼多多 | 搜索栏在顶、分类九宫格、促销 banner、双列商品瀑布流、底部标签栏 |
| **形态** | 微信小程序 | 移动端优先、窄容器、一屏一件事、底部 tab 导航 |

## 二、颜色（只有这些，不许多）

| 用途 | 色值 | 说明 |
|---|---|---|
| 页面底色 | `#f5f5f7` | 苹果官网的商品页底色（浅灰，不是纯白也不是米色） |
| 卡片/浮层底 | `#ffffff` | 纯白 |
| 主色（按钮/链接/选中） | `#0071e3` | 苹果蓝；悬停 `#0077ed` |
| 主文字 | `#1d1d1f` | 苹果正文黑 |
| 次要文字 | `#6e6e73` | 说明文字 |
| 弱文字 | `#86868b` | 辅助信息 |
| 分隔线 | `rgba(0,0,0,.08)` | 0.5px 细线 |
| 价格 | `#ff3b30` | 电商惯例红（或改 `#1d1d1f` 黑，你定） |
| 点缀 | `#34c759` 绿 | 仅用于"有货/成功" |

**明确不要**：金色/棕色系、米色底、多色渐变、彩色阴影。

## 三、液态玻璃（只用在浮层，不用在内容区）

```css
/* 顶栏 */
background: rgba(255,255,255,.78);
backdrop-filter: saturate(180%) blur(20px);

/* 促销卡（内容浮层） */
background: linear-gradient(135deg, rgba(0,113,227,.10), rgba(255,255,255,.6));
backdrop-filter: blur(20px) saturate(160%);
border: .5px solid rgba(255,255,255,.75);

/* 抽屉 / 弹窗 */
background: rgba(255,255,255,.86);
backdrop-filter: saturate(180%) blur(24px);
border-radius: 20px 0 0 20px;
```

**原则**：玻璃只表达"浮在内容之上"，所以只用顶栏、banner、抽屉、弹窗。商品卡是普通白卡，不用玻璃。

## 五、间距与形状

| 项 | 值 |
|---|---|
| 基础间距 | 8 的倍数（8/16/24/32） |
| 页面左右留白 | 12px（移动端） |
| 模块间距 | 12px |

## 六、页面结构（逐屏定义）

### ① 首页
```
[吸顶] 搜索框（玻璃，占满宽） + 搜索按钮
[吸顶] 底部标签栏：首页 / 分类 / 购物车 / 我的
─────────────────────────────
① 促销 banner（玻璃卡）：小标签 + 一句话大标题 + 主按钮 + 次按钮
② 承诺条：一行 3 个短标签（正品保障 · 按规格计价 · 发货可追踪），每项一行 11px 说明
③ 分类九宫格：4 列 × 2 行，每格 44px 圆角图标 + 12.5px 名称
④ 分区「热销推荐」：双列瀑布流
     商品卡：正方形大图（#f5f5f7 底）→ 两行标题 → 规格/销量一行灰字 → 红色价格 + 小加购按钮
⑤ 分区「新品上架」：同上
[底部] 固定标签栏（安全区留白）
```

### ② 列表页
```
顶部搜索 + 横向分类胶囊（可滑动） + 右侧排序下拉
双列商品瀑布流（同首页卡片）
上滑加载更多 / 到底提示
```

### ③ 商品详情
```
主图（正方形，可左右滑）
标题 · 价格（红）· 销量
规格选择区（颜色/尺寸，胶囊按钮，缺货置灰划线）
数量选择（加减 + 最多 N 件提示）
服务承诺一行（正品 · 免运费 · 7 天退换）
[吸底] 左：加入购物车（次）  右：立即购买（主蓝）
```

### ④ 购物车
```
商品行：小图 + 标题 + 规格 + 单价 + 加减器 + 删除
[吸底] 合计金额（红） + 去结算（主蓝，全宽胶囊）
```

### ⑤ 结算 / 订单 / 我的
```
结算：地址卡（可展开新增）→ 配送偏好 → 金额明细（商品/运费/应付）→ 提交订单（吸底）
订单：状态时间轴 + 金额明细 + 物流位
我的：头像/昵称 · 我的订单 · 收货地址 · 退出
```

### ⑥ 后台（运营端）
```
沿用同一套颜色与卡片规范（浅底 + 白卡 + 主蓝按钮），不用玻璃
左栏导航 + 内容区表格；核心操作按钮统一 999px 胶囊
```
